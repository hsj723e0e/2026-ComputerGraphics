# 모델링 변환 실습

솔루션에서 **test18을 시작 프로젝트로 설정**하고 **x64**로 실행한다.
test16처럼 GLFW, GLEW, GLM과 `shader.h`를 사용하며, `InitBuffer`,
`drawScene`, `Reshape`, `keyCallback`, `Timer`, `Move`로 구성했다.
도형의 정점과 면은 `read_obj_file()`로 `cone.txt`(원뿔), `cube.txt`(정육면체),
`sphere.txt`(구), `pyramid.txt`(사각뿔)에서 읽는다.
직접 exe를 실행할 때는 작업 디렉터리를 이 test18 폴더로 지정한다.

파일 읽기 코드는 test16의 교수님 코드 흐름을 따른다.
`fopen_s` → `fgets`로 개수 세기 → `fseek` → `malloc` →
`fgets`와 `sscanf_s`로 정점·면 저장 → `fclose` 순서이다.
`Vertex`, `Face`, `ObjData`에 읽은 뒤 GPU에 보낼 배열로 옮긴다.
색상 처리를 위해 `Face.color`와 `usemtl` 읽기를 추가했다.

텍스트 파일은 test16과 같은 OBJ 형식이다. `v x y z`는 정점,
`f 1//1 2//1 3//1`은 삼각형을 이루는 정점 번호(1부터 시작)를 뜻한다.
`//` 뒤 법선 번호는 읽기만 하며 현재 렌더링에는 사용하지 않는다.
`usemtl color0`부터 `usemtl color5`까지는 이후 면에 적용할 색을 지정한다.
정점 좌표나 면 번호를 수정하고 프로그램을 다시 실행하면 변경이 반영된다.

초기 도형은 왼쪽 원뿔, 오른쪽 정육면체이다. 좌표계와 도형 모두
x축과 y축으로 30도 기울어져 있다. 축 색은 x 빨강, y 초록, z 파랑이다.

| 키 | 기능 |
| --- | --- |
| 1 / 2 / 3 | 처음 왼쪽 객체 / 처음 오른쪽 객체 / 둘 다 선택 (기본값 3) |
| x / X | 객체 자신의 x축으로 +5 / -5도 자전 |
| y / Y | 객체 자신의 y축으로 +5 / -5도 자전 |
| r / R | 중앙 y축으로 +5 / -5도 공전 |
| a / A | 제자리에서 1.1배 확대 / 1.1로 나누어 축소 |
| b / B | 원점 기준 확대 / 축소 (위치도 같은 비율로 변화) |
| d / D | 좌 / 우 이동 |
| e / E | 위 / 아래 이동 |
| t | 두 객체가 원점을 통과해 2초 동안 자리 교환 |
| u | 한 객체는 위, 다른 객체는 아래로 돌아 2초 동안 자리 교환 |
| v | 반대 비율로 확대·축소하면서 자전·공전, 다시 누르면 정지 |
| c | 두 객체를 구·사각뿔로 교체, 다시 누르면 원뿔·정육면체 |
| s | 위치, 회전, 크기, 도형, 선택, 애니메이션 초기화 |
| q | 종료 |

대문자는 Shift+키로 입력한다(Caps Lock도 지원).
객체 번호는 자리를 교환해도 처음 선택한 객체를 계속 가리킨다.
t/u/v/c는 선택과 관계없이 두 객체 모두에 적용된다.
수동 변환 키를 누르면 애니메이션을 멈추고 현재 상태에서 변환한다.
크기는 너무 작거나 커지는 것을 막기 위해 0.05~5 범위로 제한한다.

## 행렬 적용 순서

`projection * Rx(30) * Ry(30) * T * rotation * S`

오른쪽부터 적용하므로 크기 변경, 자체 회전, 위치 이동 순서이다.
자전은 `rotation * R`로 객체의 로컬 축에 적용한다.
공전은 중앙 y축 회전행렬을 위치와 방향에 함께 적용한다.
`a`는 크기만, `b`는 크기와 위치를 함께 바꾼다.
