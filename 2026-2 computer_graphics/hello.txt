
GLEW (GL Extention Wrangler): OpenGL 축 기능이나 최신 OpenGL 함수들을 프로그램에서 사용할 수 있도록 연결해주는 역할
 현재 OpenGL Context 에서 사용할 수 있는 OpenGL함수들을 찾아서 사용할 수 있도록 GLEW를 초기화한다.
 사용 방법) 헤더파일 추가 후 초기화 함수 호출
#include <glew.h>
glewInit();
 핵심 규칙: glewInit()은 반드시 OpenGL Context 생성 이후에 호출




GLFW (GL Frame Work)
 OpenGL 프로그램을 실행하기 위한 윈도우와 OpenGL Context를 만들고, 키보드·마우스 입력과 이벤트 등을 처
리할 수 있도록 해주는 크로스 플랫폼 라이브러리
 OpenGL은 화면에 그림을 그리는 기능만 제공
 GLFW는
 1. 윈도우 생성 및 관리
 2. openGL context 생성 및 관리
 3.  키보드/마우스 입력 등 사용자 입력과 이벤트 처리, 시간 등의 기능 수행
 사용자 입력과 이벤트 처리는 폴링(Polling) 방식 또는 콜백 (Callback) 방식을 사용
 폴링 방식: 내가 계속 물어본다
 콜백 방식: 이벤트가 발생하면 GLFW가 나를 호출한다.



<GL FrameWork 흐름도>
1. GLFW초기화
2. OpenGL버전 설정
3. 윈도우생성
4. OpenGL컨텍스트활성화
5. GLEW초기화
6. 렌더링루프
7. 윈도우종료



GLFW (GL FrameWork)
	GLFW에서 사용자 입력(키보드, 마우스 등)이나 윈도우 이벤트 처리 방식
		폴링방식(Polling) (상태 조회 방식) : 프로그램이 반복적으로 현재 상태를 직접 확인하는 방식
		콜백방식(Callback) (이벤트 처리 방식) : 이벤트가 발생하면 GLFW가 자동으로 사용자 함수를 호출


// main안에 그리고 while안에 들어 있어야 할 것들 // wait제외
glfwSwapBuffers(GLFWwindow* window); 더블 버퍼링 기법으로 화면 깜빡거림 해결 
glfwPollEvents(void) : 운영체제의 이벤트 큐에 쌓여있는 이벤트를 가져와 처리하는 함수
glfwWaitEvents(void): 이벤트를 기다리게 하는 함수 - 이 함수는 이벤트가 발생할 때까지 대기
